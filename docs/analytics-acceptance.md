# Проверка аналитического модуля CLI

## Цель проверки

Проверить работу команды analyze, вывод диагностических
результатов и отсутствие повторных выводов при повторном импорте.

## Окружение

- macOS
- Docker Compose
- PostgreSQL
- Отдельный тестовый экземпляр logparser-ruslan-check
- Тестовый файл samples/app.log

## Результаты проверки

| Сценарий | Ожидаемый результат | Фактический результат |
|---|---|---|
| Анализ пустой БД | Нет совпадений | Нет совпадений |
| Первый импорт | 15 новых записей | 15 новых записей |
| Команда analyze | CHECKOUT_CHAIN | CHECKOUT_CHAIN |
| Команда trace f7a8b9 | 3 записи, 2 ошибки | 3 записи, 2 ошибки |
| Повторный импорт | 0 новых, 15 дубликатов | 0 новых, 15 дубликатов |
| Повторный анализ | Один диагностический вывод | Один диагностический вывод |

## Обнаруженный инцидент

- Правило: CHECKOUT_CHAIN
- Хост: api01
- Программа: shop-api
- Trace ID: f7a8b9
- Связанных ошибочных событий: 2

Через 0,5 секунды после начала операции зафиксирована
недоступность сервиса Inventory. Через 9,8 секунды
после начала операции зафиксирована отмена заказа.

Программа выдала рекомендацию проверить доступность
сервиса и повторы запроса.

## Заключение

Команда analyze успешно обнаруживает проверенный сценарий
связанных ошибок и выводит диагностическую рекомендацию.
Повторный импорт файла не приводит к дублированию результата.

Проверка правила DB_LINK и нагрузочное тестирование
будут выполнены отдельно.
